# Основные Файлы Terraform 

- <span style="color: green;"><strong>maint.tf</strong></span>: Обычно используется для основных компонентов инфраструктуры
- <span style="color: green;"><strong>variables.tf</strong></span>: Определения переменных, используемых в инфраструктуре
- <span style="color: green;"><strong>outputs.tf</strong></span>: Блоки вывода для отображения значений в терминале или передачи в другие модули
- <span style="color: green;"><strong>providers.tf</strong></span>: Конфигурации и требования провайдеров
- <span style="color: green;"><strong>terraform.tfvars</strong></span>: Задаёт значения для переменных, обычно игнорируется через .gitignore
